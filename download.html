Install

Four steps, about two minutes

Run the installer

Open the downloaded BirdFlew-setup.exe. If Windows says “Windows protected your PC”, click More info and then Run anyway — Windows shows this for new software from small publishers.

Click Install

No administrator password needed. Bird Flew installs for you only and adds a Start-menu shortcut.

Sign in with your key

Paste the key from your email. Bird Flew shows every app the key includes.

Install your software

Click Install next to an app. Bird Flew checks the download is genuine and installs it — nothing else to do.
